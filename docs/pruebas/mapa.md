carpeta de cada repositorio vive cada tipo de prueba.

- `JdbcArbolRepositoryTest` comprueba la consulta SQL contra un PostgreSQL real (por ejemplo, que el
  último análisis sea de verdad el más reciente).
- `ConsultarArbolesTest` comprueba la regla de negocio con un repositorio falso en memoria: no necesita
  base de datos y corre en milisegundos.
- `ArbolesApiTest` manda un evento real de API Gateway al handler de Lambda: valida permisos, códigos de
  error y el JSON exacto.
- `campo.e2e.ts` abre la web en el navegador y comprueba que la persona ve los árboles en el mapa.
